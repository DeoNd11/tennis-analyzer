🔑 Как получить персональный токен (1 минута):
  1. Откройте страницу создания токена: GitHub Fine-grained Tokens ↗
  2. Нажмите «Generate new token».
  3. В поле Token name напишите: Tennis Analyzer Cloud.
  4. В блоке Repository access выберите: «Only select repositories» → выберите tennis-analyzer.
  5. В блоке Repository permissions найдите строку Contents и переключите на «Access: Read and write».
  6. Нажмите зелёную кнопку Generate token внизу, скопируйте токен (начинается с github_pat_) и вставьте в поле ниже:
